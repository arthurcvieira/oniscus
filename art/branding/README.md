# Oniscus visual identity

*English · [Português](README.pt-BR.md)*

Approved by Arthur on 2026-10-21. Full canvas: https://claude.ai/artifact/Hr9qhLwVV8hFMf7daXWQCN

## Files

- `oniscus-mascot.svg`: the mascot (a yellow-headed isopod), main logo.
- `oniscus-mascot-icon.svg`: the same drawing in a square frame, for the menu icon, the dock and the favicon.
- `oniscus-logo.ansi`: the mascot as coloured truecolor blocks, 40 columns by 15 lines, for the terminal. In fastfetch use `"logo": {"type": "file-raw", "source": "/usr/share/oniscus/logo.ansi"}`.
- `reference-photo.png`: the reference photo the mascot was traced from.

## Palette (dark theme)

| Name | Hex | Use |
|---|---|---|
| Yellow | #F7C948 | accent (text on it: #121519) |
| Honey | #FFE58F | glow, hover, links |
| Amber | #C99412 | pressed accent |
| Beak | #F28C28 | warnings |
| Shell | #4E3527 | warm details |
| Moss | #4CC27A | success |
| Charcoal | #121519 | background, terminal |
| Graphite | #1C2026 | windows, dock |
| Slate | #2A3038 | bars, fields |
| Border | #3A424C | borders |
| Mist | #E6E9EC | main text |
| Isopod grey | #9AA4AF | secondary text |

Fonts: Nunito (brand, converted to outlines), Noto Sans (interface), Noto Sans Mono (terminal). All under the SIL OFL.
