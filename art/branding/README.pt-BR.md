# Identidade visual do Oniscus

*[English](README.md) · Português*

Aprovada pelo Arthur em 2026-10-21. Canvas com tudo: https://claude.ai/artifact/Hr9qhLwVV8hFMf7daXWQCN

## Arquivos

- `oniscus-mascot.svg`: mascote (isópode de cabeça amarela), logo principal.
- `oniscus-mascot-icon.svg`: o mesmo desenho em quadro quadrado, para o ícone `start-here`, o dock e o favicon.
- `oniscus-logo.ansi`: o mascote em blocos coloridos (truecolor), 40 colunas por 15 linhas, para o terminal. No fastfetch use `"logo": {"type": "file-raw", "source": "/usr/share/oniscus/logo.ansi"}`.
